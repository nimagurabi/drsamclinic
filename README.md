# اپلیکیشن اختصاصی اندروید کلینیک دکتر سام (Dr. Sam Clinic)

این پروژه سورس کامل اپلیکیشن نیتیو اندروید (Kotlin) است که مطابق با آخرین استانداردهای گوگل پلی (Target SDK 35 / Android 15) توسعه یافته است.

---

## 📱 امکانات پیاده‌سازی شده

- **استاندارد گوگل پلی:** خروجی اتوماتیک در فرمت **Android App Bundle (.aab)** و **APK**.
- **طراحی مدرن و اسپلش اسکرین:** پشتیبانی کامل از SplashScreen API اندروید ۱۲ به بعد.
- **کنترل هوشمند قطعی اینترنت (Offline Handling):** نمایش صفحه ارور بومی زیبا به همراه دکمه «تلاش مجدد» در صورت قطع بودن اتصال.
- **کشیدن برای رفرش (Swipe to Refresh):** کاربر با کشیدن صفحه به پایین می‌تواند صفحه را تازه کند.
- **نوار پیشرفت لودینگ (Progress Bar):** نمایش وضعیت بارگذاری صفحات به شکل نوار مدرن.
- **پشتیبانی از آپلود مدارک و دوربین:** کاربران در بخش ووکامرس یا نوبت‌دهی می‌توانند فایل یا تصویر از گالری/دوربین انتخاب و ارسال کنند.
- **مدیریت درگاه‌های پرداخت و لینک‌ها:** باز شدن درگاه‌های بانکی شاپرک/زرین‌پال بدون مشکل در اپ، و هدایت تماس‌ها (`tel:`) و واتساپ به برنامه‌های بومی گوشی.

---

## 🚀 راهنمای سریع دریافت فایل نصبی (APK) و فایل گوگل پلی (AAB) از طریق گیت‌هاب

برای دریافت فایل‌های خروجی بدون نیاز به نصب هیچ نرم‌افزاری روی سیستمتان، مراحل زیر را طی کنید:

### گام اول: ساخت یک ریپازیتوری در گیت‌هاب
1. وارد سایت [GitHub.com](https://github.com) شوید و لاگین کنید.
2. روی دکمه **New repository** کلیک کنید.
3. یک نام انتخاب کنید (مثلاً `drsamclinic-app`) و آن را **Public** یا **Private** بگذارید.
4. تیک گزینه‌های "Add a README" را نزنید و دکمه **Create repository** را بزنید.

### گام دوم: ارسال کدها از سیستم شما به گیت‌هاب
یک ترمینال (PowerShell یا Git Bash) در همین پوشه باز کنید و دستورات زیر را اجرا کنید (آدرس ریپازیتوری خود را جایگزین کنید):

```bash
git init
git add .
git commit -m "Initial commit for Dr Sam Clinic Android App"
git branch -M main
git remote add origin https://github.com/نام_کاربری_شما/drsamclinic-app.git
git push -u origin main
```

### گام سوم: دریافت فایل خروجی
1. پس از Push کردن، وارد صفحه ریپازیتوری در گیت‌هاب شوید و به تب **Actions** بروید.
2. مشاهده می‌کنید که پروسه ساخت خودکار آغاز شده است (حدود ۲ تا ۳ دقیقه طول می‌کشد).
3. پس از سبز شدن عملیات، روی نام کار کلیک کنید؛ در بخش پایین صفحه (قسمت **Artifacts**)، سه فایل زیر آماده دانلود هستند:
   - `drsamclinic-debug-apk`: فایل نصبی برای تست مستقیم روی گوشی شما
   - `drsamclinic-release-apk`: فایل نصبی نسخه نهایی
   - `drsamclinic-google-play-aab`: فایل باندل برای بارگذاری روی کنسول گوگل پلی

---

## ⚠️ چک‌لیست مهم هاست ایران پیش از ارسال به گوگل پلی

گوگل پلی اپلیکیشن شما را توسط روبات‌ها و ارزیاب‌های خارج از ایران بررسی می‌کند. برای جلوگیری از ریجکت شدن:
1. **تیکت به پشتیبانی هاست ایران:** 
   > «سلام؛ لطفاً دسترسی آی‌پی‌های خارج از کشور (بین‌المللی) را برای دامنه drsamclinic.com باز بگذارید تا ربات‌های بررسی گوگل‌پلی با خطای مسدودی روبرو نشوند.»
2. **فعال بودن گواهی SSL:** مطمئن شوید آدرس سایت با `https://` بدون هیچ خطای امنیتی باز می‌شود.
